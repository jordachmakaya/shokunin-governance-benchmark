# Repository authority

This repository is an autonomous BOXED system laboratory.

Before any write:

1. Read `MEMORY.md`.
2. Read `.shokunin/systems/SYSTEM_REGISTRY.json`.
3. Read `.shokunin/systems/ACTIVE_ASSIGNMENTS.json`.
4. Stay inside the active assignment's write roots and exact write files.

Public contracts are promises. Changing a public contract is a migration, not routine implementation. Never edit another owner's BoxedZone, root configuration, lockfile, registry, or public output boundary without an active integration assignment.

Development hooks under `.shokunin/hooks/` govern construction of this repository only. They must never be copied into Harbor task workspaces or treated as an experimental intervention.
